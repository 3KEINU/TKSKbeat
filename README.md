# TKSKbeat

**選んで、鳴らして、お祝いしよう！**

TKSKbeat は、高咲陽菜さんのお誕生日をお祝いするために作った、ブラウザで遊べる音楽トイです。
音楽の知識がなくても、好きな音を組み合わせるだけで、自分だけのバースデービートを作れます。

**▶ [TKSKbeat で遊ぶ](https://3keinu.github.io/TKSKbeat/)**

## あそびかた

1. **再生する** — まずはビートを鳴らしてみよう。
2. **ビートを選ぶ** — メロディ、コード、ベース、ドラムなどを好きな組み合わせに。
3. **ボイスで遊ぶ** — パッドをタップして声や効果音を鳴らそう。録音して曲に重ねることもできます。
4. **完成！** — できあがったビートを聴いて、共有しよう。

ボイスを使わず、ビートの組み合わせだけで完成させてもOK！

## この作品について

正解も、音楽の知識もいりません。
いろいろ試して、「これ、好きかも」と思える組み合わせを見つけてもらえたらうれしいです。
